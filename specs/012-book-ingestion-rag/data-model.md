# Data Model: RAG Ingestion

**Date**: 2025-12-16

This document defines the data structures used in the RAG ingestion process. The primary data entity is the `TextChunk`, which is stored as a "Point" in Qdrant.

## Entity: TextChunk (Qdrant Point)

A `TextChunk` represents a single piece of content that has been extracted, cleaned, and vectorized. Each `TextChunk` is stored as a point in the Qdrant vector database.

### Fields

- **`id`** (UUID | required): A unique identifier for the point. This can be generated using Python's `uuid` library.
- **`vector`** (float array | required): The dense vector embedding of the text content, generated by the Cohere model. The dimension of this vector will be 1024, corresponding to the `embed-english-v3.0` model.
- **`payload`** (object | required): A JSON object containing the metadata and the original text content.
  - **`content`** (string | required): The raw text content of the chunk.
  - **`url`** (string | required): The source URL from which the text was extracted.
  - **`title`** (string | optional): The title of the page, extracted from the `<title>` HTML tag.
  - **`section`** (string | optional): The nearest heading or section title relevant to the chunk. This helps provide context during retrieval.

### Example Qdrant Point

```json
{
  "id": "a1b2c3d4-e5f6-7890-1234-567890abcdef",
  "vector": [0.12, 0.45, -0.23, ...],
  "payload": {
    "content": "This is a chunk of text from the documentation about setting up a development environment.",
    "url": "https://shaziasama.github.io/Physical-AI-Humanoid-Robotics/docs/tutorial-basics/create-a-document",
    "title": "Create a Document | Physical AI & Humanoid Robotics",
    "section": "Development Environment Setup"
  }
}
```

### State Transitions

The `TextChunk` entity is immutable once created. It is generated during the ingestion process and is not expected to change. If the source content is updated, a new ingestion run should be performed, which may involve overwriting or creating a new Qdrant collection.
