# Quickstart Guide: Frontend-Backend Integration for RAG Chatbot

**Feature Branch**: `001-rag-fe-be-integration`
**Created**: December 17, 2025
**Feature Spec**: [specs/001-rag-fe-be-integration/spec.md](specs/001-rag-fe-be-integration/spec.md)
**Implementation Plan**: [specs/001-rag-fe-be-integration/plan.md](specs/001-rag-fe-be-integration/plan.md)

This guide provides basic instructions to get started with and test the frontend-backend integration for the RAG Chatbot feature.

## Prerequisites

Before starting, ensure you have:

1.  **FastAPI RAG Backend Running**: The backend, which handles RAG queries and Qdrant integration, must be running and accessible.
    *   Refer to its specific documentation for setup and running instructions (e.g., related to `013-openai-rag-agent` spec).
    *   Note the URL where the FastAPI application is listening (e.g., `http://localhost:8000`).
2.  **Docusaurus Frontend Project Setup**: Your local Docusaurus project should be set up and its dependencies installed.
    *   Navigate to the `docusaurus-text-book/` directory.
    *   Install dependencies if you haven't already: `npm install` or `yarn install`.

## Running the Integration

### Step 1: Start the FastAPI RAG Backend

Ensure your FastAPI RAG backend is operational. For example:

```bash
cd path/to/your/fastapi-rag-backend
uvicorn main:app --reload --port 8000
```
*(Replace `path/to/your/fastapi-rag-backend` with the actual path to your backend project.)*

### Step 2: Start the Docusaurus Frontend

From your Docusaurus project directory:

```bash
cd docusaurus-text-book/
npm run start
# or yarn start
```
This will start the Docusaurus development server, typically at `http://localhost:3000`.

### Step 3: Access and Interact with the Chatbot

1.  Open your web browser and navigate to the Docusaurus site (e.g., `http://localhost:3000`).
2.  Locate the embedded chatbot interface on any book page. (Specific location will depend on implementation, but it should be visible.)
3.  Type a question related to the book content into the chatbot input field (e.g., "What is ROS 2?").
4.  Submit the query.

## Performing a Test Query

To validate the end-to-end integration:

1.  **Query Example**: "Explain the concept of RAG."
2.  **Expected Outcome**: The chatbot interface should display a response generated by the AI agent, based on the book content. The response should be semantically relevant to the query.
    *   If the backend includes source attribution, you might also see links or references to the relevant sections of the book.
3.  **Error Handling Test**:
    *   If you stop the FastAPI backend (Step 1) and then try to submit a query, the frontend chatbot should display a graceful error message, indicating that it cannot connect to the backend.

## Troubleshooting

-   **Backend Not Responding**: Check if the FastAPI backend is running and accessible at the configured URL/port. Check backend logs for errors.
-   **Frontend Not Displaying Chatbot**: Ensure the chatbot component has been correctly embedded into Docusaurus pages. Check browser developer console for JavaScript errors.
-   **No Relevant Response**: Verify that the Qdrant instance is populated with relevant embeddings and that the RAG agent logic in the backend is functioning correctly.
