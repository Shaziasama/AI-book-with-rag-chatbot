# Data Model for Retrieval and Validation of Book Content Embeddings

## Entities

### BookContentEmbedding
-   **Description**: A vector representation of a segment of the book's text, suitable for similarity search in Qdrant.
-   **Fields**:
    -   `vector`: (Array of Floats) The high-dimensional embedding vector generated by Cohere.
    -   `payload`: (Object) Metadata associated with the text chunk.
        -   `text`: (String) The original text chunk from the book.
        -   `book_id`: (String) Identifier for the book.
        -   `chapter`: (Integer, Optional) Chapter number.
        -   `page_start`: (Integer, Optional) Starting page number of the chunk.
        -   `page_end`: (Integer, Optional) Ending page number of the chunk.
        -   `section_id`: (String, Optional) Unique identifier for the section within the book.
        -   `source_url`: (String, Optional) URL to the original source if applicable.
-   **Relationships**: Stored within `QdrantCollection`.

### QdrantCollection
-   **Description**: A logical container within Qdrant that stores `BookContentEmbedding` vectors and their associated payloads.
-   **Key Attributes**:
    -   `name`: (String) Unique name of the collection (e.g., `book-embeddings-collection`).
    -   `vector_size`: (Integer) Dimension of the embedding vectors (must match Cohere model output).
    -   `distance`: (String) Metric used for similarity search (e.g., `Cosine`).
    -   `optimizers_config`: Configuration for background optimization processes.
-   **Operations**:
    -   Creation/Deletion of collection.
    -   Insertion of `BookContentEmbedding`s.
    -   Retrieval of `BookContentEmbedding`s via similarity search.

### SemanticQuery
-   **Description**: A natural language query provided by a user (or test system) that is converted into an embedding for similarity search.
-   **Fields**:
    -   `query_text`: (String) The original human-readable query.
    -   `query_embedding`: (Array of Floats) The vector representation of `query_text` generated by Cohere.
-   **Operations**:
    -   Generation of `query_embedding` using Cohere API.
    -   Used to search the `QdrantCollection`.

### RetrievedChunk
-   **Description**: A `BookContentEmbedding` retrieved from `QdrantCollection` based on a `SemanticQuery`, along with its similarity score.
-   **Fields**:
    -   `book_content_embedding`: (BookContentEmbedding) The retrieved embedding and its payload.
    -   `score`: (Float) Similarity score indicating relevance to the `SemanticQuery`.
-   **Validation Attributes (for testing)**:
    -   `is_relevant`: (Boolean) Flag indicating if the chunk matches an `ExpectedSection` (ground truth).
    -   `expected_sections_matched`: (Array of Strings) List of `section_id`s from `ExpectedSection` that this chunk matched.

### ExpectedSection (Ground Truth for Validation)
-   **Description**: A pre-defined section of the book content that a specific `SemanticQuery` is expected to retrieve. Used for validation against actual `RetrievedChunk`s.
-   **Fields**:
    -   `query_id`: (String) Identifier for the test query.
    -   `expected_section_id`: (String) Unique identifier for the expected section in the book.
    -   `expected_text_snippets`: (Array of Strings) Key text snippets from the expected section to aid in matching.
    -   `tolerance_score`: (Float, Optional) Minimum score expected for a retrieved chunk to be considered relevant for this section.
