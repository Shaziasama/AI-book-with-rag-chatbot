# API Contract: RAG Agent Development with OpenAI Agents SDK and FastAPI

This document specifies the API contract for the RAG Agent FastAPI backend, focusing on the `/query` endpoint.

## OpenAPI Specification (Simplified)

### Path: `/query`

#### Operation: `POST`

Sends a user question to the RAG agent and receives a contextually relevant answer.

-   **Description**: Submits a natural language query to the RAG agent for processing against pre-stored book content.
-   **Operation ID**: `ask_rag_agent`
-   **Tags**: `rag-agent`

#### Request Body: `QueryRequest`

-   **Content Type**: `application/json`
-   **Schema**:
    ```json
    {
      "type": "object",
      "properties": {
        "query_text": {
          "type": "string",
          "description": "The natural language question from the user."
        },
        "user_id": {
          "type": "string",
          "format": "uuid",
          "description": "Optional: Unique identifier for the user making the query.",
          "nullable": true
        }
      },
      "required": ["query_text"]
    }
    ```
-   **Example**:
    ```json
    {
      "query_text": "What are the main themes of the book?",
      "user_id": "a1b2c3d4-e5f6-7890-1234-567890abcdef"
    }
    ```

#### Responses:

-   **`200 OK`**: Successful response with the agent's answer and citations.
    -   **Description**: The query was processed successfully, and a response generated.
    -   **Content Type**: `application/json`
    -   **Schema**: `QueryResponse`
        ```json
        {
          "type": "object",
          "properties": {
            "response_text": {
              "type": "string",
              "description": "The coherent and accurate answer generated by the RAG agent."
            },
            "citations": {
              "type": "array",
              "items": {
                "type": "object",
                "properties": {
                  "content_id": {
                    "type": "string",
                    "format": "uuid",
                    "description": "Unique identifier for the cited content segment."
                  },
                  "source_document_id": {
                    "type": "string",
                    "format": "uuid",
                    "description": "Identifier for the original document (e.g., book) the content came from."
                  },
                  "page_number": {
                    "type": "integer",
                    "description": "Page number within the source document, if available."
                  },
                  "text_snippet": {
                    "type": "string",
                    "description": "A small snippet of the cited text for context."
                  }
                }
              },
              "description": "List of content segments cited in the response."
            },
            "query_id": {
              "type": "string",
              "format": "uuid",
              "description": "The unique identifier of the processed query."
            }
          },
          "required": ["response_text", "citations", "query_id"]
        }
        ```
    -   **Example**:
        ```json
        {
          "response_text": "The main themes of the book include the exploration of artificial intelligence, robotics, and human-robot interaction.",
          "citations": [
            {
              "content_id": "c1d2e3f4-g5h6-7890-1234-567890abcdef",
              "source_document_id": "d1e2f3g4-h5i6-7890-1234-567890fedcba",
              "page_number": 15,
              "text_snippet": "Artificial intelligence and robotics are central to the narrative..."
            }
          ],
          "query_id": "q1w2e3r4-t5y6-7890-1234-567890asdfgh"
        }
        ```
-   **`400 Bad Request`**: Invalid input provided.
    -   **Description**: The request body is malformed or missing required fields.
    -   **Schema**:
        ```json
        {
          "type": "object",
          "properties": {
            "detail": {
              "type": "string",
              "description": "A message describing the error."
            }
          }
        }
        ```
-   **`503 Service Unavailable`**: External service (Qdrant/OpenAI) is unavailable.
    -   **Description**: The agent is unable to process the request due to an issue with an external dependency.
    -   **Schema**:
        ```json
        {
          "type": "object",
          "properties": {
            "detail": {
              "type": "string",
              "description": "Service temporarily unavailable. Please try again later."
            }
          }
        }
        ```

## Error Messages (Based on Clarification)

-   **Qdrant/OpenAI Unavailability**: "Service temporarily unavailable. Please try again later."
-   **Irrelevant Query**: "I'm sorry, I cannot find relevant information in the book for your query. Please rephrase or try a different question."
