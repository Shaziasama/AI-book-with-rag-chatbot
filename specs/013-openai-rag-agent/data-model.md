# Data Model: RAG Agent Development with OpenAI Agents SDK and FastAPI

This document outlines the key entities and their attributes for the RAG Agent system, derived from the feature specification.

## Entities

### 1. User Query

Represents an incoming question from a user to the RAG agent.

-   **`query_id`** (UUID, Primary Key): Unique identifier for the query.
-   **`timestamp`** (datetime): Time when the query was received.
-   **`text`** (string): The actual query string (e.g., "What is the capital of France?").
-   **`user_id`** (UUID, Optional): Identifier for the user who made the query. Can be null if the user is anonymous or not tracked.

### 2. Retrieved Content

Represents a segment of book content retrieved from Qdrant that is relevant to a user's query.

-   **`content_id`** (UUID, Primary Key): Unique identifier for the retrieved content segment.
-   **`source_document_id`** (UUID): Identifier for the original document (e.g., book, chapter) the content came from. This links back to the source material.
-   **`page_number`** (integer) or **`start_end_offset`** (tuple of integers): Indicates the location of the content within the source document.
-   **`text`** (string): The actual textual content retrieved from the book.
-   **`embedding_id`** (string): Identifier for the embedding in Qdrant, linking this content to its vector representation.

### 3. Agent Response

Represents the final answer generated by the RAG agent in response to a user's query.

-   **`response_id`** (UUID, Primary Key): Unique identifier for the agent's response.
-   **`query_id`** (UUID, Foreign Key): Links to the `query_id` that prompted this response, establishing a direct relationship between query and response.
-   **`timestamp`** (datetime): Time when the response was generated.
-   **`response_text`** (string): The generated answer text (e.g., "The capital of France is Paris, according to page 25 of 'History of Europe'.").
-   **`citations`** (list of `content_id`s, Foreign Keys): A list of `content_id`s referencing the `Retrieved Content` segments that were used to generate this response, enabling traceability and verification.
-   **`model_used`** (string): Name or identifier of the OpenAI model used for generating the response (e.g., "gpt-4", "gpt-3.5-turbo").

## Relationships

-   **One-to-Many**: A `User Query` can have one `Agent Response`.
-   **Many-to-Many**: An `Agent Response` can be based on multiple `Retrieved Content` segments, and a single `Retrieved Content` segment can contribute to multiple `Agent Responses` (via citations).

## Data Validation Rules

-   **`query_id`, `content_id`, `response_id`**: Must be valid UUIDs.
-   **`timestamp`**: Must be valid datetime objects.
-   **`text`, `response_text`**: Cannot be empty.
-   **`citations`**: Each `content_id` in the list must correspond to an existing `Retrieved Content` entry.

## State Transitions

-   Not applicable for these entities, as they represent immutable records of interactions rather than stateful objects with life cycles.
